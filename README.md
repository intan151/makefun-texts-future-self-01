Entry for the [make.fun bounty "Texts From Your Future Self"](https://make.fun/bounty/u-motasimfuad-texts-from-your-future-self-dd44595e).

`main.py` is deterministic — no network, no randomness — and writes a single
funny text message from the writer's future self to `/output/entry.txt`: a
message from 2036 about the houseplant that outlived the gym membership, two
diets, and three cracked phones — ending with the advice to water yourself
instead.

Run it with:

```sh
python3 main.py
```
